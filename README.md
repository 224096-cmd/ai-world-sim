# 神々の年代記 — AI世界シミュレーター (PWA)

WorldBox と Fantasy Map Simulator の面白さを一つにした、**神視点の国家シミュレーションゲーム**です。

大地を隆起させ、森を植え、入植者を落とす。生まれた国は勝手に都市を築き、王を継ぎ、同盟を結び、戦争を始め、やがて滅びます。あなたはその歴史を、上から眺めたり、隕石を落として捻じ曲げたりします。

- **サーバー不要・完全オフライン動作**。すべての計算がブラウザ内で完結します
- PC / Android / iPhone で動く PWA(ホーム画面にインストール可能)
- 外部APIも課金もなし。広告はメニューの中だけで、ゲーム画面には出ません

---

## 1. 遊び方

### 起動したら

世界が自動生成され、いくつかの国が芽吹いた状態から始まります。上部の速度ボタン(`×1`〜`×8`)を押すと時間が流れ出します。

### 画面の見かた

| 場所 | 内容 |
| --- | --- |
| **上部バー** | 年・月・季節、現存国家数と総人口、マップモード、時間の速度 |
| **右上のミニマップ** | 世界全体。クリックでその場所へ飛べます |
| **下部の「神器帯」** | 神の力。6つのカテゴリからツールを選びます |
| **左のドロワー**(☰) | 国家一覧・年代記・統計・設定 |

### マップモード

- **政治** — 国ごとの色で領土を塗り分け
- **地形** — 地形をそのまま見る(領土は薄く表示)
- **人口** — 人口の多い都市ほど明るく輝く
- **外交** — 選択中の国から見た敵(赤)・同盟(緑)・休戦(橙)
- **技術** — 技術水準が高い国ほど明るい

### 基本操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | 地図を動かす(塗りツール選択中はその場に力を使う) |
| ホイール / ピンチ | 拡大・縮小 |
| クリック | 選択中のツールを使う |
| `Space` | 一時停止 / 再開 |
| `1`〜`5` | 速度(停止・×1・×2・×4・×8) |
| `Q` / `W` | 検分 / 地図移動 |
| `B` | 筆の太さを切り替え |
| `M` | マップモードを切り替え |
| `Tab` | メニューの開閉 |
| `Esc` | パネルを閉じる |

## 2. 神の力(神器帯)

### 🔍 検分

- **検分** — タイル・都市・国家を調べます。**ここで国をクリックすると「選択中の国」になります**
- **移動** — 地図を動かすだけのモード

> 👑 マークの付いたツールは「選択中の国」に対して働きます。先に検分で国を選んでください。

### 🌲 自然

隆起 / 沈降 / 山脈 / 植林 / 砂漠化 / 凍結 / 水域 / 豊穣 / 金鉱・鉄鉱・宝石の埋設。

大陸を作り替えられます。肥沃な土地は都市が育ち、金鉱は国庫を、鉄鉱は兵力を潤します。

### 🐑 生命

- **入植者** — 無主の地に落とすと村ができ、**新しい国家が誕生します**。他国の領土に落とすと移民(人口+300)
- **羊 / 狼** — 狼は羊や住民を襲います
- **竜召喚** — 都市を焼き払いながら数年さまよい、飽きると去っていきます

### 🏰 文明

建国 / 築城 / 領土授与 / 金貨の雨 / 叡智 / 軍団召喚。
特定の国をひいきして、世界の覇者に育て上げることができます。

### ☄ 災厄

落雷 / 隕石 / 火山 / 業火 / 疫病 / 地震 / 竜巻 / 呪い。

火は森を伝って燃え広がり、焦土になった土地は数十年かけてゆっくり再生します。疫病は隣の都市へ飛び火します。

### 🕊 外交

- **和平の光** — その国のすべての戦争を終わらせます
- **戦の種** — 最も憎んでいる国と開戦させます
- **同盟の絆** — 最も親しい国と同盟を結ばせます

## 3. 世界のしくみ

**1ティック = 1ヶ月、12ティック = 1年**で進みます。

- **領土** — 国境から肥沃な土地へじわじわ広がります。山は越えにくく、海は渡れません
- **都市** — 人口が増えると建物が大きくなり、城壁が高くなります。国庫に余裕があると新しい都市を建てます
- **戦争** — 軍団が最寄りの敵都市へ行進し、途中で敵軍と出会えば会戦。都市を包囲し、城壁を削り切ると陥落。周辺6タイルの領土も奪います
- **国境侵食** — 都市を落とさなくても、優勢な側が前線をじわじわ押し込みます
- **首都陥落** — 残った最大都市へ遷都します。都市がゼロになると国家は滅亡します
- **王位継承** — 王は年を取り、崩御します。世継ぎがいなければ継承危機となり、新しい王朝が始まります。功績のある王には「征服王」「賢王」などの二つ名が付きます
- **反乱** — 首都から遠く、不穏の高い都市は独立戦争を起こします。大帝国ほど辺境の統治が緩みます
- **住民** — 都市の人口に応じて住民が歩き回ります。火や溶岩、狼、竜巻で命を落とします

すべての出来事は**年代記**に記録されます。左のメニューから、戦争・興亡・神託・災厄で絞り込んで読めます。

## 4. 設定・セーブ

左メニューの「設定」から:

- **新しい世界を創る** — 大きさ(小・中・大)、シード値、陸地の割合、初期国家数を指定して作り直せます
- **保存 / 読込** — ブラウザのローカルストレージに保存します。**30秒ごとに自動保存**され、次回開いたときは続きから始まります
- **表示** — 地名の表示、住民の表示のオン・オフ

> ブラウザのサイトデータを消すとセーブも消えます。

## 5. 広告について

A8.net のアフィリエイト広告を `src/ads.ts` にまとめてあります。**300×250 が15本、320×50 が15本、合計30本**がすべて登録済みです。

### 出る場所

広告は**左メニュー(ドロワー)の中だけ**に出ます。地図・ツールベルト・上部バーには一切重なりません。メニューを閉じている間、画面に広告は1つも表示されません。

| 場所 | サイズ |
| --- | --- |
| メニュー下部に固定 | 320×50 |
| 各タブの本文の末尾 | PC/横画面は300×250、スマホは320×50 |
| 国家一覧・年代記の途中 | 320×50(一覧が十分に長いときだけ) |

タブごとに違う広告から始まり、同じ画面に同じ広告が並ばないようになっています。メニューを開いている間は差し替わらないので、読んでいる最中にチラつきません。

### 調整のしかた

`src/ads.ts` の先頭にある `AD_CONFIG` を触ります。

```ts
export const AD_CONFIG = {
  enabled: true,     // false にすると広告が全部消えます
  placeholder: false, // タグ未設定の枠に点線を出すか(本番は false 推奨)
  showLabel: true    // 「広告」ラベルを出すか(ステマ規制対応。true 推奨)
};
```

新しい広告を増やすときは、A8.net でコピーしたHTMLを `AD_SLOTS` の対応するサイズの配列に、バッククォート `` ` `` で囲んで追加するだけです。配列の先頭ほど露出が多くなります。

## 6. 開発環境の準備

### 必要なもの

- [Node.js](https://nodejs.org/) 18以上(20推奨)

```bash
node -v
```

### 起動

```bash
npm install     # 初回のみ
npm run dev     # 開発サーバー (http://localhost:5173)
```

### ビルド・確認

```bash
npm run build   # dist/ に出力
npm run preview # ビルド結果を確認
```

### 公開(Cloudflare Pages / Workers)

```bash
npm run deploy  # vite build && wrangler deploy
```

初回は `npx wrangler login` が必要です。

## 7. ファイル構成

```
src/
├── main.ts                 起動・ゲームループ・入力処理・セーブ
├── style.css               全UIスタイル
├── ads.ts                  広告タグと配置(メニュー内のみ)
├── pwaRegister.ts          Service Worker登録
├── core/                   ── シミュレーション本体(描画に依存しない)
│   ├── types.ts            型定義・地形/資源コード・ツール定義
│   ├── rng.ts              シード付き乱数(再現性のため)
│   ├── noise.ts            値ノイズ / fBm / リッジノイズ
│   ├── worldgen.ts         大陸・山脈・気候・河川・資源の生成
│   ├── nameGenerator.ts    6文化圏の国名・都市名・人名・二つ名
│   └── simulation.ts       国家・都市・軍・人物・外交・災害・神の力
└── ui/                     ── 表示層
    ├── renderer.ts         Canvas描画・カメラ・ミニマップ
    └── hud.ts              上部バー・神器帯・ドロワー・検分カード
```

### 設計メモ

- **タイルデータは typed array**(`Uint8Array` / `Float32Array`)で保持し、大きな世界でも軽く動きます
- **地形と国境は offscreen canvas にベイク**し、変化したタイルだけを塗り直します。毎フレームの描画は `drawImage` と動くもの(都市・軍・住民・エフェクト)だけです
- **乱数はすべてシード付き**です。同じシードなら同じ世界が生まれます
- 表示のなめらかさのため、軍と住民は前の月の位置から補間して描いています

## 8. よくある質問

**Q. 国が増えすぎる / 減りすぎる**
設定から初期国家数を変えられます。0にすると完全に無人の世界から、入植者を落として始められます。

**Q. 動作が重い**
設定で世界の大きさを「小」にするか、「住民・動物を表示」をオフにしてください。

**Q. 保存できない**
プライベートブラウジングではローカルストレージが使えない場合があります。

**Q. スマホにインストールしたい**
ブラウザのメニューから「ホーム画面に追加」を選んでください。オフラインでも遊べます。
